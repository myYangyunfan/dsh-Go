# goapp 真机验收清单

代码在桌面端跑绿不等于手机上能用。这份清单覆盖 goapp 全部「只有真机能证明」的行为，按顺序做一遍大约 15 分钟。填完下面的表头，结论才有意义——`CONTRIBUTING.md` 要求写清 ABI、Android 版本、启动方式和机型，缺一项就无法复现。

## 表头（每次验收先填）

| 项 | 值 |
|---|---|
| APK | `dsh-go-<版本>-<arm64\|x64>.apk` |
| ABI | arm64-v8a / x86_64 |
| Android 版本 | 例如 13 / API 33 |
| 机型 | 例如 Pixel 6 / 小米 13 |
| 启动方式 | PRoot 兼容启动（默认）/ 直接启动（开发者选项） |
| 桌面图标 | 默认 / LauncherMist 系列其一 |
| locale | 中文 / English |

## 1. 商店下载安装

1. 打开插件面板 → `goapps` 管理器。
2. 在「商店」里点 `go单词`。
3. 期望：出现 toast「已安装 go单词」，同一行从商店列表消失，`已安装 = 1`。
4. 期望：断开网络后再装一个未安装的条目 → toast 报「下载失败: network」，已装的 goapp 不受影响。

## 2. 打开 goapp（面板内）

1. 点已安装列表里的 `go单词`。
2. 期望：全屏打开，标题是 goapp 自己的标题，内容是该 goapp 的面板（不是空白，不是「unknown page」）。
3. 返回：回到管理器面板，不退出 App。

## 3. 桌面快捷方式直达

1. 长按桌面图标 → 快捷方式里应出现该 goapp（最多 5 个）。
2. 点它。
3. 期望：直接进这个 goapp 的全屏界面，**不经过 App 首页**。
4. 关掉 App 再点一次：仍直达同一个 goapp。

> 若无快捷方式：先确认该 goapp 是「已启用」；再确认桌面图标切换后快捷方式仍在（`ShortcutsPlugin.rebind`）。

## 4. 每 goapp 独立会话

1. 在 goapp 里发一句能让它记住的话（例如「记住 42」）。
2. 右上角「对话」→「新建对话」。
3. 期望：新对话里**不记得** 42；切回旧对话，仍记得。
4. 删除当前对话：期望自动落到剩下的最近一个，而不是空白页。
5. 杀掉 App 进程重开：期望仍停在上次那个对话。

## 5. 禁用 / 删除

1. 在管理器里关掉该 goapp 的开关。
2. 期望：桌面快捷方式消失；管理器里仍是「已安装」。
3. 重新打开开关：快捷方式回来，**会话还在**（禁用不清数据）。
4. 删除该 goapp：期望它的会话一起被清掉；再点一次「导入」期望提示导入 0 个（包体已随删除一起删掉，不会被复活）；重新从商店安装时是真下载，不是本地登记。
5. 手工装的那份也要能删干净：把同一个包解压到 `$DSH_HOME/goapps/inbox/my-word/`（目录名故意跟包名 `goapp-demo-word` 不同），导入后删除，期望 `inbox/my-word` 整个消失，「导入」提示 0 个。只按包名删的话这一步会留下目录，测试里对应「remove deletes the folder a hand-dropped package actually lives in」。

## 6. 更新

商店里现在是 `word 0.2.2`，旧版 tarball（`goapp-demo-word-0.1.0.tar.gz`）也留在同一个目录里，所以这一节可以真做出来。两版的差别是**看得见**的：0.1.0 的 5 张词卡、面板底下没有版本行；0.2.2 有 7 张词卡，面板底部多一行 `v0.2.2 · 7`。

1. 把 `plugins/goapp/store/goapp-demo-word-0.1.0.tar.gz` 下载到手机，用管理器的「导入」装进去 —— 此时安装版本是 0.1.0 —— 那一版的面板**没有**底部版本行，能看到「剩余 5」就是装对了。
2. 打开商店，同一个 goapp 那一行应显示 `0.1.0 → 0.2.2`，图标是刷新而不是下载。
3. 点它。期望：toast「已更新」，面板底部变成 `v0.2.2 · 7`，卡数 7 张而不是 5 张。
4. 检查更新前手动关掉的「启用」开关仍是关的，之前的会话也还在（更新不覆盖用户字段）。
5. 再点一次（版本已相同）：期望不重复下载、界面不动。
6. 断网再点：toast 报「下载失败」并说明原因，0.2.2 照常能打开（升级失败不卸载）。

## 7. 深链

在电脑上执行（手机与电脑同一 route）：

```bash
adb shell am start -a android.intent.action.VIEW -d "dshgo://open/panel/goapp-demo-word/word"
```

期望：直接落到该 goapp；把 package 改成不存在的名字，期望看到明确的「未知页面」提示而不是闪退。

## 8. 回归（改动共享层时必须做）

- 本机 PRoot 引擎：全新安装 → 启动 → 发一条消息成功。
- SSH 远程主机：连接 → 发消息成功。
- 普通对话里的插件面板、工具卡片仍正常。
- 切换桌面图标后，最近会话快捷方式仍能打开对应会话。

## 已知无法在桌面端验证的部分

- 桌面快捷方式的发布与回跳（`ShortcutManager` 只有真机有）。
- `dshgo://` 深链（`LinkTrampolineActivity` 的 intent 处理）。
- PRoot 兼容启动与直接启动的差异。
- 语音输入、手机操控、更新安装——本次 goapp 改动不涉及，但同一次回归里顺手确认没有连带损坏。
